Practica 01
Gestor de Contactos

Practica realizada en Java que administra una agenda de contactos

El proyecto incluye:
- GestorContactosFile.java: uso de `FileReader` / `FileWriter`
- GestorContactosBufferBuffer.java: uso de `BufferedReader` / `BufferedWriter`

---Proceso para ejecutar el programa--

Ubicarse en la carpeta del proyecto:

cd "C:\Ubicacion"


Compilar las clases:

javac cd src GestorContactosFile.java / src GestorContactosBufferBuffer.java / GestorContactos.java


Ejecutar el programa:

java GestorContactos

java GestorContactosFile

java GestorContactosBuffer

Seguir las opciones del menú:

File 
1. Agregar contacto
2. Mostrar todos los contactos
3. Buscar contacto por nombre
4. Eliminar archivo de contactos
5. Salir
Seleccione una opción:

Buffer
1. Agregar contacto
2. Ver contactos
3. Buscar contacto por nombre
4. Eliminar contacto
5. Eliminar archivo de contactos
6. Salir
